# EduBot - Digital Marketing

## Deskripsi
EduBot adalah chatbot berbasis AI yang dikembangkan menggunakan n8n untuk membantu pengguna mempelajari digital marketing.

## Fitur
- Menjawab pertanyaan seputar SEO.
- Memberikan informasi tentang pemasaran media sosial.
- Membantu memahami content marketing.
- Menjelaskan iklan digital dan strategi pemasaran online.
- Menggunakan AI Agent untuk memproses pertanyaan pengguna.

## Teknologi
- n8n untuk workflow automation.
- Google Gemini sebagai model AI.
- Simple Memory untuk mempertahankan konteks percakapan.

## File Proyek
- `EduBot - Digital Marketing.json` — file ekspor workflow n8n.

## Cara Menggunakan
1. Unduh file JSON dari repository ini.
2. Impor file tersebut ke n8n.
3. Konfigurasikan kembali kredensial yang diperlukan.
4. Aktifkan workflow dan uji chatbot.

## Catatan
Kredensial API dan token autentikasi tidak disertakan dalam repository ini.
